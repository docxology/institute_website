# atlas

Generated page-by-page coverage of the source PDF: `index.html` is a searchable
index, and `page-NNN.html` holds the extracted text, optional thumbnail, and
previous/next pager for each PDF page.

Every HTML file here is written by `src/build.mjs` (`npm run build`); do not
hand-edit them. See [AGENTS.md](AGENTS.md).
