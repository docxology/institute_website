# AGENTS.md — `institute_website/assets`

## Scope

- Static assets referenced by the generated pages. No build step: files are
  served as committed, and `build.mjs` only links to them.

## Layout

- `css/styles.css` — the single stylesheet for every page.
- `js/site.js`, `js/atlas.js` — classic scripts loaded with `defer`.
- `img/source-page-*.png` — PDF page thumbnails, regenerated by
  `scripts/extract_pdf.py`.
- `source/AII.pdf` — the committed source document the site is built from.

## Gotchas

- Asset paths in generated HTML are relative with a `../` prefix on nested
  pages; keep new assets reachable from both the root and `atlas/`.
- `img/` and `source/` contents are pipeline outputs — regenerate with
  `npm run extract` rather than editing by hand.
