# AGENTS.md — `institute_website/src`

## Scope

- Source of truth for the site. Everything under the repo root that is
  generated (`*.html`, `atlas/`, `robots.txt`, `sitemap.xml`) is produced from
  this directory by `build.mjs`.

## Layout

- `build.mjs` — Node ESM static generator, no dependencies. Reads
  `content/site-data.json` and `content/pdf-pages.json`, writes the site.
- `content/site-data.json` — hand-curated public pages, navigation, metrics.
- `content/pdf-pages.json` — generated by `scripts/extract_pdf.py`; do not
  hand-edit.

## Gotchas

- `build.mjs` runs top-level `build()` on import; there is no CLI flag parsing.
- The canonical Pages origin used for `robots.txt` and `sitemap.xml` is
  hardcoded in `build.mjs`; update it there, not in the generated files.
- Requires Node >= 22 (`package.json` `engines`).
