# AGENTS.md — `institute_website/src/content`

## Scope

- Input data for `src/build.mjs`. Nothing here is rendered directly; the
  generator turns both JSON files into HTML.

## Layout

- `site-data.json` — hand-curated: `site` metadata, `navigation`, `metrics`,
  and the public `pages` (slug, title, lede, sections, cards, source range).
- `pdf-pages.json` — generated by `scripts/extract_pdf.py`: `source` metadata,
  `sections` ranges, and one entry per PDF page (number, slug, title, section,
  summary, full extracted text).

## Gotchas

- `pdf-pages.json` is a committed build artifact (~400 KB). Never hand-edit it;
  regenerate with `npm run extract` and commit deliberately.
- Page slugs must stay unique across `site-data.json` and `pdf-pages.json`:
  `build.mjs` writes `<slug>.html` for both sets.
