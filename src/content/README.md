# content

Input data for `src/build.mjs`.

- `site-data.json` — hand-curated site metadata, navigation, metrics, and the
  public pages (slug, title, lede, sections, cards, source range).
- `pdf-pages.json` — generated by `scripts/extract_pdf.py`; one entry per PDF
  page plus the section ranges used by the atlas. Never hand-edit it.

See [AGENTS.md](AGENTS.md).
